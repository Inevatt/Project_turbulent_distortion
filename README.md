#### Картинки обязательно больше, чем 256x256 иначе prewiev будет неправильно работать, но не упадет
#### Обязательно persistent_workers = False, иначе обучение неккоректно работает

## Что обязано совпадать между четырьмя прогонами

Между четырьмя обучениями меняется **ровно один аргумент — `--level`**.
Иначе разница между строками матрицы перестанет объясняться только
физикой обучающих данных.

Код гарантирует совпадение весов, порядка батчей, кропов и D/r₀ (всё —
функции от `cfg["seed"]`) и сверяет конфиг при `--resume`.

Код **не** проверяет три вещи:

**1. Нарезку тайлов.** Сплит считается заново из `source_id.npy` при
каждом запуске, а конфиг хранит только имя папки. Перезапуск
`make_tiles.py` меняет число источников → меняет перестановку → меняет
тестовый набор и кропы. Все проверки при этом пройдут, матрица
посчитается и будет выглядеть нормально.

> Перенарезал тайлы — удалить `experiments/` и обучить все четыре уровня
> заново.

Вероятная причина перенарезки — требования D2/D3 к `margin_px`: если
носителю PSF станет мало 16 px, понадобится тайл больше 256. Решать
до первого прогона.

**2. Код.** Правка `optics.py`, `data.py`, `unet.py`, `metrics.py`,
`distortion/*.py` между прогонами делает строки несравнимыми.

**3. Конфиг.** `configs/base.yaml` не меняется в течение серии.

### Намеренное исключение

`configs/seed2.yaml` (повторный прогон для оценки шумового порога):
отличаются `seed` и `out_dir`, обязаны совпадать `split_seed` и
`eval_seed` — иначе шум прогона смешается с шумом тестовой выборки.

### Чеклист

Перед серией — записать:

```
sha256sum tiles/source_id.npy
git rev-parse HEAD
```

Перед `eval_matrix.py` — сверить оба значения и проверить, что конфиги
прогонов идентичны:

```
diff experiments/d0/config.yaml experiments/d3/config.yaml
```
